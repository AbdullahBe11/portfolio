# Abdullah Berro: Portfolio

Personal developer portfolio built with Next.js (App Router), TypeScript and Tailwind CSS.

## Run locally

```
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All text lives in `src/data.ts`. The CV download is `public/Abdullah_Berro_CV.pdf`; replace that file to update it.

## Deploy

Push to GitHub, import the repo in Vercel, and deploy with the default Next.js settings.
